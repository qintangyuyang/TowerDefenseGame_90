# 90 秒守点：游戏说明与按钮操作

## 一、游戏简介

这是一个 2D 竖屏守点小游戏。

玩家需要守住位于地图底部的基地，坚持 **90 秒**。敌人会从上方两个出生点出现，沿着蛇形道路进攻基地。两座炮塔会自动攻击敌人，玩家还可以主动释放范围技能。

- 坚持到 90 秒：胜利
- 基地血量归零：失败
- 每次战斗结束后可以重开
- 最高分保存在本地

当前版本为 PC 原型版本，使用 Unity 2022.3 + Built-in Render Pipeline。

---

## 二、快速开始

1. 打开场景：

```text
Assets/Scenes/SampleScene.unity
```

2. 点击 Play；
3. 在首页点击 `Start`；
4. 等待敌人出现，炮塔会自动攻击；
5. 点击 `Skill` 按钮，再点击战场释放技能；
6. 坚持 90 秒，或者观察基地血量归零后的失败结算。

## 三、玩法规则

### 敌人

| 敌人 | 特点 |
|---|---|
| 疾行者 Runner | 速度快、血量低、近战攻击基地 |
| 重装兵 Tank | 速度慢、血量高、攻击距离更远 |

两种敌人都会沿 `RoundPoint` 的路径点移动。

### 炮塔

- 场景中有 `Tower1` 和 `Tower2`；
- 自动寻找射程内离基地最近的敌人；
- 自动发射子弹；
- 射程、伤害、射速、子弹速度都来自 JSON。

### 主动技能

- 点击 `Skill` 按钮进入瞄准；
- 鼠标移动到战场后显示范围圈；
- 左键点击地面释放；
- 对范围内所有敌人造成伤害；
- 释放后进入冷却；
- 冷却期间按钮变灰，并显示剩余秒数。

当前 JSON 配置：

```text
伤害：50
半径：3.5
冷却：12 秒
```

### 胜负

```text
战斗时间 >= 90 秒  → 胜利
基地血量 <= 0       → 失败
```

### 分数

战斗中的 `Score` 主要来自击杀：

```text
击杀数 × perKill
```

结算时最终分数为：

```text
击杀分 + 剩余基地血量 × perHp + 胜利奖励
```

当前 JSON：

```text
perKill = 100
perHp = 10
winBonus = 1000
```

## 四、界面说明

### HomePanel 首页

显示游戏标题、最高分和开始按钮。

```text
Canvas/HomePanel
├─ TitleText
├─ BestScoreText
└─ StartButton
```

### HUDPanel 战斗界面

```text
Canvas/HUDPanel
├─ TimeText        剩余时间
├─ BaseHpText      基地血量
├─ KillNum         击杀数
├─ ScoreNum        当前分数
├─ PauseButton     暂停
└─ SkillButton     主动技能
```

`SkillButton` 下还有：

```text
SkillButton
├─ CooldownMask    冷却遮罩
└─ SkillText       技能文字/冷却秒数
```

### PausePanel 暂停界面

```text
Canvas/PausePanel
├─ PauseTitle
├─ ResumeButton
└─ RestartButton
```

暂停时 `Time.timeScale = 0`，敌人、子弹、倒计时和技能冷却都会停住。

### TempPanel 结算界面

```text
Canvas/TempPanel
├─ VictoryText      胜利文本
├─ DefeateText      失败文本
├─ ResultScoreText  本局最终得分
├─ ResultBestText   最高分
└─ ReopenText       重开按钮
```

> 当前 `DefeateText` 的占位文本拼写是 `defeate`，正式版建议改成 `Defeat`；节点名可以保留，避免破坏已有引用。

## 五、按钮说明

| 按钮/节点 | 所在面板 | 功能 | 代码绑定 |
|---|---|---|---|
| `StartButton` | HomePanel | 开始新一局 | `GameManager.StartGame()` |
| `PauseButton` | HUDPanel | 暂停游戏 | `GameManager.PauseGame()` |
| `ResumeButton` | PausePanel | 继续游戏 | `GameManager.ResumeGame()` |
| `RestartButton` | PausePanel | 暂停中重开 | `GameManager.RestartGame()` |
| `ReopenText` 上的 Button | TempPanel | 结算后重开 | `GameManager.RestartGame()` |
| `SkillButton` | HUDPanel | 进入技能瞄准 | `PlayerSkill.BeginAim()` |

### 重要说明

这些按钮的 `OnClick` 不需要手动在 Inspector 里拖方法。

代码已经绑定了：

- `GameManager.BindButtons()` 绑定开始、暂停、继续、重开、Reopen；
- `PlayerSkill.Start()` 绑定技能按钮。

如果 Inspector 里再手动加一遍 `OnClick`，可能出现一次点击触发两次的问题。

## 六、键盘和鼠标操作

| 操作 | 功能 |
|---|---|
| 鼠标左键 | 点击 UI 按钮；技能瞄准时释放技能 |
| 鼠标右键 | 取消技能瞄准 |
| `Q` | 进入技能瞄准（键盘备用操作） |
| `Esc` | 游戏中暂停；暂停中继续 |
| `F1` | 切换技能 VFX 高质量/简化质量 |

### 技能操作流程

```text
点击 Skill 按钮
→ 鼠标移到战场
→ 出现范围圈
→ 左键点击地面
→ 释放技能
→ 进入冷却
```

注意：

- 鼠标停在 UI 上时不会显示范围圈；
- 必须把鼠标移到战场区域；
- 右键可以取消瞄准。

## 七、技能视觉效果

当前技能包含：

1. 范围提示：地面圆环；
2. 释放效果：自定义 Shader 圆环扩散；
3. 命中效果：敌人位置的白色小圆环。

高质量模式：

- 两层 Shader 圆环；
- 第二层带旋转/噪声；
- 强度更高。

简化模式：

- 一层 Shader 圆环；
- 无第二层；
- 强度较低。

按 `F1` 可以在运行时切换，方便测试和录视频。

TA 参数在：

```text
Assets/StreamingAssets/GameData/game_data.json
```

示例：

```json
"skill": {
  "damage": 50,
  "radius": 3.5,
  "cooldown": 12.0,
  "vfx": {
    "color": "#FFA51F",
    "duration": 0.35,
    "intensity": 1.5,
    "ringWidth": 0.12,
    "highQuality": true
  }
}
```

## 九、AI 使用说明

### 使用的 AI 工具

本项目在开发过程中使用了 **DeepSeek Harness 中的 AI 编程助手（DeepSeek 模型）**，主要用于辅助开发，而不是替代开发者完成最终实现。

### AI 参与的内容

AI 主要在以下环节提供了建议和代码草稿：

- 游戏整体架构和模块拆分；
- `GameManager`、`Enemy`、`Tower`、`Bullet`、`PlayerSkill` 等脚本的代码骨架；
- JSON 配置结构、字段命名和数据校验思路；
- 首页、HUD、暂停、结算等 UI 流程和按钮绑定方式；
- 技能范围圈、释放圆环、命中反馈的实现思路；
- 技能 Shader 和高/低两档 VFX 的方案；
- 部分报错排查，例如范围圈被 Tilemap 遮挡、UI 引用未赋值、按钮没有绑定等；
- 本文档的结构和文字整理。

### AI 没有参与的内容

- 项目中的美术资源、Tilemap、字体和其他第三方素材不是 AI 生成的；
- AI 没有直接修改 Unity 场景、Prefab 或项目设置；
- 最终代码不是 AI 自动提交的，而是由开发者手动接入、调整并在 Unity 中运行验证。

### 人工审核和验证

AI 给出的代码和建议都经过人工筛选和修改，不能保证一次就能直接运行。实际开发中由开发者完成：

- 将脚本放入工程并处理 Unity 编译错误；
- 在 Inspector 中绑定场景对象、UI 和 Prefab；
- 调整数值、布局和视觉效果；
- 运行游戏，验证刷怪、炮塔、技能、暂停、胜负、重开和最高分；
- 对 AI 给出的方案做取舍，保留适合当前项目的部分。

因此，AI 在本项目中的定位是：

```text
开发辅助工具
→ 提供思路、代码草稿和排查建议
→ 由开发者审核、修改、接入和测试
```
